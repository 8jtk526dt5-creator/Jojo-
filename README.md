# Jojo

Jeu de combat en pixel art, en un seul fichier HTML, sans dépendance. Tu invoques ton Stand, enchaînes les rafales et déclenches ta pose ultime contre trois adversaires.

## Jouer

Ouvre `index.html` dans un navigateur (iPhone, Android ou ordinateur). Avec GitHub Pages, le jeu est jouable directement depuis le lien du dépôt.

## Commandes

| Action | Tactile | Clavier |
| --- | --- | --- |
| Bouger | ◀ ▶ | Flèches ou A / D |
| Sauter | SAUT | Haut, W ou Espace |
| Frapper | COUP | J |
| Stand (rafales plus fortes, la jauge se vide) | STAND | K |
| Pose ultime (barre orange pleine) | POSE ULTIME | L |

## Combattants

- **Salomon** et son Stand TIC-TAC : l'ultime arrête le temps.
- **Mirella** et son Stand ROSE NOIRE : l'ultime tire un rayon écarlate.

Trois adversaires à battre : Brutus Kane, Nox Vesper et le Docteur Orage.

Tous les personnages et les Stands sont originaux.
