# Jojo

Jeu de combat en pixel art, en un seul fichier HTML, sans dépendance. Garde, esquive, enchaîne les coups, invoque ton Stand et déclenche ta pose ultime contre trois adversaires.

## Jouer

Ouvre `index.html` dans un navigateur (iPhone, Android ou ordinateur). Avec GitHub Pages, le jeu est jouable directement depuis le lien du dépôt. Sur iPhone, le jeu se joue aussi en horizontal.

## Commandes

| Action | Tactile | Clavier |
| --- | --- | --- |
| Bouger | ◀ ▶ | Flèches ou A / D |
| Sauter | SAUT | Haut, W ou Espace |
| Frapper (appuie plusieurs fois pour enchaîner jab, crochet, coup de pied) | COUP | J |
| Invoquer / renvoyer le Stand (avec le Stand, COUP lance une rafale) | STAND | K |
| Garde (tenir appuyé, réduit fortement les dégâts de face) | GARDE | S ou Maj |
| Esquive (courte invincibilité) | ESQUIVE | U ou E |
| Pose ultime (barre orange pleine) | ULTIME | L |

## Combattants

- **Salomon** et son Stand TIC-TAC : l'ultime arrête le temps. Les coups encaissés par l'adversaire s'accumulent et tombent d'un coup quand le temps repart.
- **Mirella** et son Stand ROSE NOIRE : l'ultime tire un rayon écarlate (on peut l'esquiver en sautant).

Trois adversaires, chacun avec son style et son décor :

- **Brutus Kane** (rue néon) : fonce sur toi avec un coup de pied.
- **Nox Vesper** (toit sous la pluie) : se téléporte dans ton dos et lance des orbes.
- **Docteur Orage** (port sous l'orage) : fait tomber la foudre à ta position, fuis le cercle au sol.

Tous les personnages et les Stands sont originaux.
